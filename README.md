# Quick Start!
***If you already installed easyAPT, run "sudo easyAPT" to start it up.***

For quick easyAPT setup, open a terminal and paste this into it.

```bash
gh release download --repo pointer-laptop13244/easyAPT --pattern easyaptsetup.sh
chmod +x easyaptsetup.sh
./easyaptsetup.sh
```
*This command downloads the easyAPT setup script, makes it executable, and starts it up. The setup script then installs easyAPT.*

# More Information
- Bash is highly recommended
- The "dialog", "iputils-ping" (or similar name), "curl", "gh", and "git" packages are required for full operation of easyAPT.
- Most functions require an internet connection.
- **Command to start it:** "sudo easyAPT"

# How it works - a simple summary
easyAPT uses common Debian package management tools, like apt-get and dpkg, as backends.
When the user chooses something to do, easyAPT runs the right command.

For example, choosing to fix the packages runs
```bash
dpkg--configure -a >/dev/null 2>&1
```
*Tip: the ">/dev/null 2>&1" command at the end discards unnecessary command output.*

I decided to use "apt-get" instead of "apt" the best I could, because apt-get is meant for scripts and apt for humans.
Plus, apt can display an annoying warning when it detects it's being used in a script.
